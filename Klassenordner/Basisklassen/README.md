# Basisklassen

Die fünfzehn Universalklassen besitzen jeweils einen eigenen Ordner mit `klasse.json` als Inhaltsquelle und `index.html` als erzeugter Seite. Das gemeinsame Layout und die Erzeugung sind im [Klassenregister-README](../README.md) beschrieben.

Texte in `klasse.json` bearbeiten und anschließend im Almanach `npm run build:classes` ausführen.
