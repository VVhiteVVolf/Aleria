# Nordmänner

Die acht gelieferten Nordmänner-Klassen liegen als eigenständige Inhaltsseiten vor. Ihre Quellen sind `klasse.json`; `kultur.json` bündelt die gemeinsame Geschichte des nordischen Kriegertums und den überlieferten Grundkampfstil.

Die Seiten enthalten bewusst noch keinen Stufenplan, keine Attackenfreischaltungen und keine automatische Vergabe an Charakterbögen. Dafür reserviert die Klassenregistry den Status `progressionStatus: "not-authored"`, sodass das spätere Levelsystem ergänzt werden kann, ohne die Lorestruktur neu aufzubauen.
