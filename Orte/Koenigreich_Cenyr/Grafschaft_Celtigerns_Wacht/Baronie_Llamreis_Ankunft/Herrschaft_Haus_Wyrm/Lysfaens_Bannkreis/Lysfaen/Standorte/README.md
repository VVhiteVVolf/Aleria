# Standorte in Lysfaen

Dieser Ordner enthaelt einzelne bearbeitbare Einrichtungen innerhalb von Lysfaen.

Jeder Standort bekommt:

- einen eigenen Registry-Eintrag in `Orte/orte.registry.js`
- eine eigene `ort.data.js`
- eine eigene stabile URL ueber `/Orte/zunft.html?id=<id>`
- einen eigenen Firebase-Dokumentbereich ueber diese ID

Die Standorte liegen bewusst unter `Lysfaen/Standorte/`, nicht direkt unter `Lysfaens_Bannkreis`, weil sie zur Siedlung Lysfaen gehoeren.
