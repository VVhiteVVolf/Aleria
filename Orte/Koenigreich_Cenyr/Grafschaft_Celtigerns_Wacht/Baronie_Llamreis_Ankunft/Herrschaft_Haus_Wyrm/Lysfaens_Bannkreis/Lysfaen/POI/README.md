# POI für Lysfaen

Dieser Ordner ist für spätere konkrete Orte innerhalb Lysfaens oder innerhalb von Lysfaens Bannkreis vorgesehen.

Beispiele:

- Tavernen
- Shops
- Höfe
- Werkstätten
- öffentliche Plätze
- einzelne Orte im Bannkreis

Jeder POI soll später einen eigenen Unterordner mit eigener `ort.data.js` bekommen.
