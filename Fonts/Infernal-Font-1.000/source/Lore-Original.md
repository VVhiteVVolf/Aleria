# Nharazim Regular 1.000

Infernale Brand-, Beschwörungs- und Vertragsschrift für Aleria. Jeder Buchstabe besitzt einen eigenen Sigillennamen und eine infernale Bedeutung.

## Paketinhalt

- `Nharazim-Regular.ttf`: installierbare Desktopschrift
- `Nharazim-Regular.woff2`: kompakter Webfont
- `Nharazim-Regular.woff`: Webfont-Fallback
- `nharazim.css`: HTML-Einbindung mit optionalem Glutstil
- `demo.html`: interaktive Testseite
- `Nharazim_Zeichentafel.png`: vollständige Vorschau

## Installation unter Windows

1. `Nharazim-Regular.ttf` öffnen.
2. Auf **Installieren** klicken.
3. In einem Programm die Schriftfamilie **Nharazim** auswählen.

## Verwendung in HTML

Fontdateien und `nharazim.css` in denselben Ordner legen:

```html
<link rel="stylesheet" href="nharazim.css">

<p class="infernales">Der Eid bindet Blut und Namen.</p>
<p class="infernales-glut">Der Preis wird entrichtet.</p>
```

Für senkrechte Vertragsschrift:

```html
<p class="infernales-glut infernales-vertrag">Blut gegen Macht</p>
```

Groß- und Kleinbuchstaben verwenden dasselbe Sigill. Punkt, Komma, Doppelpunkt, Semikolon, Ausrufezeichen, Fragezeichen, Bindestrich und deutsche Anführungszeichen besitzen eigene infernale Formen.

Die 30 Hauptsigillen sind zusätzlich im privaten Unicode-Bereich U+E200 bis U+E21D direkt erreichbar.
