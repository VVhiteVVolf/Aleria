# Bilder fuer Llysfaens Anzeigetafel

`LlysfaenTafel.webp` ist das lokale Tafelbild (4096 × 3072 Pixel), übernommen
aus „Llysfaen Tafel.png“. Registry und Tafelkonfiguration binden es als Grundbild ein.

Die aktuelle Anzeigetafel veröffentlicht ihre Inhalte unter der Registry-ID:

```text
cenyr-celtigerns-wacht-llamrais-ankunft-wyrm-llysfaen-anzeigetafel
```

Die im Bild gezeichneten Zettel gehören zum Hintergrund. Weitere bearbeitbare
Aushänge können über den bestehenden Anzeigetafel-Editor angelegt werden.
