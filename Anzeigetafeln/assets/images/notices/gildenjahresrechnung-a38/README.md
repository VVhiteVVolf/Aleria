# Das Gelbe Formular A38

Amtliche Verfahrensbekanntmachung der Gwynthorer Amtsstelle der Wolken der
Dämmerung auf deren bereits vorhandenem Plakat. Eine Veröffentlichung mit
einem Blatt; keine Quest, Belohnung oder Suche nach einer helfenden Person.
Standard-Aushangdatum: 9. Lichtkehr 1740.

Die jährliche Abrechnung heißt **Zunft- und Gildenjahresrechnung mit
Abgabenschlussausgleich**. Sie verrechnet tatsächliche Abgaben, Vorauszahlungen
und anerkannte Nachlässe beziehungsweise Befreiungen. Das Ergebnis kann eine
Nachzahlung, eine Entlastung oder eine Gutschrift sein; neue Steuersätze oder
eine besondere Abgabefrist wurden nicht erfunden.

Tewdwr Gairfân, beigeordneter Rechnungssekretär zweiter Ordnung, erläutert den
umständlichen Weg: A21 → Gelbes A38 → C14/Grünes U4 → A7/R11 → A21/N2 →
Empfang bei Frau Briallen/Wartenummer → Schalter 4/Termin → C14/Sachprüfung →
Abgabenschlussbescheid A38-E. B239 ist diesen Monat wegen Ratten geschlossen.
Die beiden genannten Amtsbediensteten sind Nebenfiguren des Aushangs;
ihnen wurden keine Familienbeziehungen oder Ämter in anderen Hierarchien zugeordnet.

Quelle: `Anzeigetafeln/tools/notices/gildenjahresrechnung-a38.mjs`.
Das Autorenpaket bindet ausschließlich das vorhandene Wolken-Plakat und
bewahrt bereits gespeicherte Positionen und fremde Inhalte.
