# Cynddelws Gesuch

Die persönliche Unterschrift wurde mit dem eingebauten image_gen erzeugt.
Original-PNG erhalten; `tools/build-troetzli-art.py` erstellt ausschließlich die
beschnittene WebP-Anzeigefassung und einen Hashbeleg. Das vorhandene einfache
bürgerliche Wachssiegel wird wiederverwendet; kein erfundenes Llythfor-Wappen.
Exakter Prompt im Diagnoseordner `gwynthor-troetzli-2026-10-31`.

Auf ausdrücklichen Nutzerwunsch gehört das Gesuch zum bestehenden Hilfe-Plakat.
Die Illustration ist Eirlys’ naive Kinderzeichnung: Trötzli schlägt aus und
verfehlt Papas Kopf. Das echte Pferdeporträt wird ausschließlich für den
Kreatureneintrag verwendet. Die generierte Skizze bleibt als Original-PNG
erhalten; der Aufbereiter erstellt nur eine kleinere WebP-Anzeigefassung.
