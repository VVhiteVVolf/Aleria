# Göttliche Gottheiten

Die neun primären Gottheiten besitzen je einen Ordner `<id>/eintrag.json` und eine erzeugte `index.html`. Beziehungen zu Götterkreisen und Religionen werden als Eintrags-IDs in `relations` gepflegt. Anleitung und Datenschema: `../../README.md` im Religionen-Wurzelordner.

Die Souveräne liegen daneben unter `../souveraene`, die Untergottheiten unter `../untergoetter`. Alle drei Gruppen werden ausschließlich in `../../data/goettlicher-kreis.json` registriert. Der neue Klerus liegt unter `../../klerus`; jedes Götterprofil verlinkt seine eigene Klerusunterseite. Symbole: `E:\Aleria\BilderRüstungen`; große Glasmalereien: `../../assets/divine-art`.
