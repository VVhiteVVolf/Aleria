# Alpin Dubhan in Gafyr-Knappenrüstung

63 vollständig neue Einzelavatare im hellen Burghof: die Katalogsets 1–6 mit je neun Bildern liegen unmittelbar hier. Das neue siebte Set liegt im Unterordner `07 - Genervt - Seufzend - Erleichtert` und enthält je drei genervte, seufzende und erleichterte Reaktionen, jeweils nach oben, zur Seite und nach vorn blickend.

Alle Bilder verwenden dieselbe neue Arbeitsreferenz: Alpin mit blauen Augen, Sommersprossen und Seitenzopf, dunklem Harnisch mit Goldkanten, Zwei-Ziegen-Hauszeichen und braunen Lederhandschuhen im sonnigen Gafyr-Burghof. Hier bezeichnet Set 7 ausdrücklich das neue Zusatzset dieses Auftrags; die allgemeine nummernstabile Katalogvorlage bleibt erhalten.
