# Blodwen Balchder – zwei Emote-Sets

Erstellt am 30. Oktober 2026 mit der AvatarWerkstatt und dem integrierten Bildgenerator (`image_gen`). Zwei 3×3-Sheets, je neun unterschiedliche Reaktionen, zusammen 18 Einzelavatare. Identität, Alter, Kleidung, Zeichenstil und warme Raumkulisse folgen dem unveränderten Originalporträt.

Export mit der unveränderten Zuschneidelogik von Avatar Splitter Pro V3: 3×3, Lücke X/Y 0, Autocrop aus. Pixelkoordinaten und Prüfsummen stehen je Set unter `Verarbeitung/<set-id>/export-manifest.json`. Originalporträt und vollständige Sheets bleiben erhalten; alle Einzelavatare liegen gemeinsam direkt in `Output`.
