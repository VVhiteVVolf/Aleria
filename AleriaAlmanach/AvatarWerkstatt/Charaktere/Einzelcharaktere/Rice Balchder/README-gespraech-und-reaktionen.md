# Rice Balchder · Reaktionsavatare

Erstellt am 30. Oktober 2026 mit dem integrierten image_gen anhand des unveränderten Stammbaum-Porträts und des vollständigen AvatarWerkstatt-Masterprompts.

Diese Sammlung enthält zwei quadratische 3×3-Sheets mit je 1254×1254 Pixeln und 18 Einzelavatare als PNG mit 418×418 Pixeln. Die V3-Zuschneidelogik wurde unverändert mit Raster 3×3, Lücken 0/0 und deaktiviertem Autocrop verwendet. Die zugehörigen Dateien stehen vollständig in `avatar-manifest.json`; andere vorhandene Werkstattfassungen bleiben erhalten.

Gesicht, Alter, Haare, Kleidung, Anime-Stil und warmer Innenraum folgen dem Referenzporträt. Jedes Emote hat eine eigene Mimik und passende freie Handgestik. Die Auswahl deckt 18 breite Reaktionsgruppen ab.

| Bildnummer | Set 1 · Gespräch, Freude und Nähe | Set 2 · Starke Gefühle und Reaktionen |
| --- | --- | --- |
| 01 | Freundlich / Begrüßend | Überrascht / Verblüfft |
| 02 | Redend / Erklärend / Deutend | Ängstlich / Erschrocken |
| 03 | Nachdenklich / Abwägend | Besorgt / Mitfühlend |
| 04 | Skeptisch / Misstrauisch | Wütend / Schreiend / Konfrontativ |
| 05 | Verwirrt / Ratlos / Unsicher | Genervt / Missbilligend / Geringschätzig |
| 06 | Schelmisch / Vertraulich flüsternd | Entschlossen / Stolz / Zuversichtlich |
| 07 | Rufend / Verkündend | Traurig / Enttäuscht / Weinend |
| 08 | Fröhlich / Herzlich lachend | Verlegen / Ertappt / Entschuldigend |
| 09 | Zuneigung / Dankbar / Erleichtert | Erschöpft / Resigniert / Überfordert |

Die Bildnummern laufen pro Sheet zeilenweise von oben links nach unten rechts.

- `Referenzen`: unverändertes Porträt und Quellenbeleg.
- `Prompts`: ausgefüllte Aufträge, vollständige tatsächlich verwendete Erstprompts und gezielte Korrekturprompts.
- `Sheets`: beide vollständigen fertigen Sheets.
- `Output`: die geprüften Einzelavatare, ohne Set-Unterordner; Dateinamen enthalten zusätzlich das jeweilige Thema.
- `avatar-manifest.json`: Zuordnung von Emotes, Ausschnittkoordinaten, SHA-256-Prüfsummen und Sichtprüfungen.
- `Originale` und `Verarbeitung`: erhaltene Zwischenfassungen und lokale Prüfübersichten.

Die ZIP-Datei enthält fertige Sheets und Einzelavatare einschließlich Emote-Liste, Aufträgen, Prompts, Referenz und Prüfmanifest. Zwischenfassungen bleiben in der Werkstatt erhalten.
