# Porträts zur Gwynthorer Lotsensuche

- `portraits/vebrand-wolfsruf.png`: Vébrand Wolfsruf, 43 Jahre, Blutbundsöldner aus Ulfsstad.
- `portraits/rob.png`: Rob, 33 Jahre, Tagelöhner in Gwynthor.

Erzeugt mit dem eingebauten Bildwerkzeug am 31. Oktober 2026. Stil:
`anime-scene-portrait` aus `docs/art/image-style-presets.json`, Tales of
Xillia/Frieren, 2:3. Die öffentlichen Figurenexporte stammen aus
`modules/gwynthor-lotsensuche/lotsensuche-characters.mjs`.

Mit `node AleriaAlmanach/scripts/build-gwynthor-lotsensuche.mjs --check` werden
Exporte und der begrenzte Import in die Charakterdatenbank kontrolliert.
Bestehende Figuren und Laufzeitressourcen werden nicht neu geschrieben.
