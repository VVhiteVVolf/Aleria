# Dice audio assets

The six MP3 files in this directory are adapted from selected WAV recordings
in **“2 dice roll (29 throws)”** by the OpenGameArt user **RPG**:

- Source: <https://opengameart.org/content/2-dice-roll-29-throws>
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- Original archive: `Dice sound.7z`

The source page describes the collection as different dice-rolling sounds for
board games and marks it as CC0. Attribution is therefore not required, but is
retained here for provenance.

## Adaptations for Aleria

Selected recordings were converted from WAV to mono MP3 at 44.1 kHz / 96
kbit/s. They were level-normalized, filtered, faded and, for the two impact
files, trimmed to short landing fragments. No mechanical result is encoded in
the audio; critical-result cues are generated locally by the application.
